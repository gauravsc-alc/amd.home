# GitHub Pages Hosting Guide

This site can be hosted on GitHub Pages as a static website generated by `python build.py`.

## Option 1: Publish From `docs/`

Use this option when you want GitHub Pages to serve the generated `docs/` folder directly.

1. Build the site:

   ```bash
   python build.py
   ```

2. Commit and push:

   ```bash
   git add .
   git commit -m "Build static site"
   git push
   ```

3. On GitHub, open the repository.

4. Go to `Settings > Pages`.

5. Under `Build and deployment`, select:

   ```text
   Source: Deploy from a branch
   Branch: main
   Folder: /docs
   ```

6. Save the setting.

Your site will be available at:

```text
https://YOUR_USERNAME.github.io/REPOSITORY_NAME/
```

## Option 2: Publish With a `gh-pages` Branch

Use this option if you have an automation workflow that builds the site and pushes only static files to `gh-pages`.

1. Push your source code to `main`.

2. Ensure the workflow runs:

   ```text
   python build.py
   ```

3. Ensure the workflow publishes the generated `docs/` output to the `gh-pages` branch.

4. On GitHub, open `Settings > Pages`.

5. Select:

   ```text
   Source: Deploy from a branch
   Branch: gh-pages
   Folder: / (root)
   ```

## GoDaddy Custom Domain

Use these steps after buying the domain from GoDaddy.

### Recommended Setup: `www.yourdomain.com`

This is the easiest and most reliable GitHub Pages setup.

1. On GitHub, open the repository.

2. Go to `Settings > Pages`.

3. In `Custom domain`, enter:

   ```text
   www.yourdomain.com
   ```

4. Save it.

5. Go to `Settings > Secrets and variables > Actions > Variables`.

6. Add a repository variable:

   ```text
   Name: CUSTOM_DOMAIN
   Value: www.yourdomain.com
   ```

7. In GoDaddy, open:

   ```text
   My Products > Domain > DNS > Manage DNS
   ```

8. Add or update this DNS record:

   | Type | Name | Value | TTL |
   | --- | --- | --- | --- |
   | CNAME | www | YOUR_USERNAME.github.io | 1 hour |

9. Push a change or manually run the GitHub workflow from the `Actions` tab.

10. Return to `Settings > Pages` and enable `Enforce HTTPS` after GitHub finishes checking DNS.

Replace `YOUR_USERNAME` with the GitHub account or organization that owns the repository.

### Optional Root Domain: `yourdomain.com`

If you also want the root domain to work, add these GoDaddy records:

| Type | Name | Value | TTL |
| --- | --- | --- | --- |
| A | @ | 185.199.108.153 | 1 hour |
| A | @ | 185.199.109.153 | 1 hour |
| A | @ | 185.199.110.153 | 1 hour |
| A | @ | 185.199.111.153 | 1 hour |

You can also add IPv6 records:

| Type | Name | Value | TTL |
| --- | --- | --- | --- |
| AAAA | @ | 2606:50c0:8000::153 | 1 hour |
| AAAA | @ | 2606:50c0:8001::153 | 1 hour |
| AAAA | @ | 2606:50c0:8002::153 | 1 hour |
| AAAA | @ | 2606:50c0:8003::153 | 1 hour |

Keep the GitHub Pages custom domain as `www.yourdomain.com` unless you specifically want the root domain as the primary address.

### GoDaddy DNS Notes

- Delete any old `CNAME` record for `www` before adding the GitHub one.
- Delete parked-domain forwarding records if they conflict with GitHub Pages.
- DNS can take a few minutes to several hours to fully update.
- GitHub may show DNS warnings until propagation finishes.
- Do not put `https://` in DNS records or in the GitHub custom domain field.

## Repository Setup

For a new repository:

```bash
git init
git add .
git commit -m "Initial website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/REPOSITORY_NAME.git
git push -u origin main
```

Replace `YOUR_USERNAME` and `REPOSITORY_NAME`.

## Project URL Settings

If the repository is named `amd.home`, the public URL is usually:

```text
https://YOUR_USERNAME.github.io/amd.home/
```

For the Jekyll config path, update `_config.yml` if you use the Jekyll version:

```yaml
baseurl: "/amd.home"
url: "https://YOUR_USERNAME.github.io"
```

The Django static build fixes `/static/` paths to relative `static/` paths, so the generated `docs/` site works under repository subpaths.

## Every Future Update

1. Edit source files in `content/`, `templates/`, or `static/`.
2. Run:

   ```bash
   python build.py
   ```

3. Preview `docs/index.html`.
4. Commit and push:

   ```bash
   git add .
   git commit -m "Update website"
   git push
   ```

## Common Problems

| Problem | Fix |
| --- | --- |
| 404 page | Check `Settings > Pages` branch and folder |
| CSS or JS missing | Re-run `python build.py` and confirm `docs/static/` exists |
| Images missing | Confirm files are in `static/images/` before building |
| Wrong custom domain | Remove or correct the domain in `Settings > Pages` |
